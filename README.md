# Reinforcement Learning Laboratory

This repository contains the implementation of Reinforcement Learning laboratory experiments developed using the **Gymnasium** library in Python. The experiments focus on exploring reinforcement learning environments, understanding agent-environment interactions, and analyzing state transitions, rewards, and episode termination.



## Objectives

- Explore Reinforcement Learning environments using Gymnasium.
- Understand the interaction between an agent and its environment.
- Observe state transitions, rewards, and termination conditions.
- Execute random actions and analyze environment behavior.
- Build a foundation for implementing RL algorithms.

## Technologies Used

- Python 
- Gymnasium
- NumPy
- Matplotlib


## Learning Outcomes

- Familiarity with Gymnasium environments
- Understanding of reinforcement learning fundamentals
- Observation of agent-environment interactions
- Analysis of rewards and episode completion
- Practical experience with Python-based RL experimentation
